# EffectCraft 国内公网账号与节点中继服务

此目录用于替代海外 Cloudflare Worker，目标部署位置为中国大陆云主机（例如腾讯云或阿里云中国内地地域）。管理版手机继续承担管理员控制与节点开关；公网主机负责账号 API、在线节点发现和加密消息中继。

## 已写入的服务能力
- PostgreSQL 持久化账号、管理员设备、节点网络开关。
- 注册/登录、个人资料、QQ/微信二选一、PNG/JPG/WebP data URI 头像。
- 管理员手机设备密钥绑定、挑战签名登录。
- 用户查询、封禁/解禁、永久封禁账号删除。
- WebSocket 节点在线会话、节点在线列表、管理员总开关、密文转发。
- HTTPS/WSS 由 Nginx 终止 TLS；WebSocket 只转发密文，不解析消息正文。

## 当前尚未达到生产验收
- 现有中继通道可以跨网络转发加密消息，但 Android 端真正的 libp2p 直连、NAT 打洞、失败自动切换中继尚未接通。
- 账号状态事件和节点中继需要在真实 APK 中验证；两台异地设备的完整注册/登录/封禁/重连/传输测试尚未通过。
- 必须配置 TLS 证书、域名和主机防火墙；本仓库不包含任何真实密钥或服务器地址。
- 上线前还需加登录限流、审计日志、备份恢复、服务监控、头像对象存储和安全测试。

## 国内主机部署
1. 准备中国大陆云主机（建议 Ubuntu LTS，至少 2 vCPU / 2GB RAM 起步），安装 Docker Engine 和 Docker Compose。
2. 若域名解析到中国大陆服务器并对外提供服务，按云厂商与主管部门要求完成 ICP 备案；腾讯云官方说明中国内地轻量服务器绑定域名对外提供服务前需完成 ICP 备案。
3. 配置域名 A 记录指向服务器公网 IPv4，准备匹配该域名的 TLS 证书。
4. 在此目录创建 certs 文件夹，放入 fullchain.pem 和 privkey.pem。
5. 复制 .env.example 为 .env，设置三个强随机密钥；绝不能把真实密钥提交到 Git。
6. 开放公网 TCP 80、443；数据库端口 5432 不得暴露公网。
7. 执行 docker compose up -d --build。
8. 检查 https://你的域名/health，必须返回 ok=true、database=true。
9. APK 的账号服务地址设置为 https://你的域名；节点连接自动使用同域名的 WSS。

## 当前重要限制
国内公网服务代码已经放入仓库，但没有购买/授权的主机、域名、证书和部署凭据，因此现在还没有真实公网实例。未部署之前，不能宣称账号服务器已经上线。
