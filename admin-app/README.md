# EffectCraft 家庭账号主机（仅安卓手机）

**不需要电脑、Docker、云服务器或公网服务器。**

把本 APK 安装在一台长期连接家庭 Wi-Fi 的安卓手机上。这台手机就是家庭账号主机：内置账号 API、SQLite 数据库和管理员页面。其他安装了 EffectCraft 的手机连接同一个家庭 Wi-Fi 后，使用本机显示的地址注册、登录和验证账号。

## 手机端启动

1. 在一台安卓手机上安装并打开「EffectCraft账号管理」APK。
2. 首次启动会显示一次性管理员密码，请先保存。管理员账号固定为 `admin`。
3. 主机手机连接家庭 Wi-Fi。登录页会显示本机 Wi-Fi 地址，例如 `http://192.168.1.23:8787`。
4. 在需要使用 EffectCraft 的其他手机上，也连接同一个家庭 Wi-Fi。在 EffectCraft 首次账号页的服务器地址中填写主机手机显示的地址。
5. 账号管理 APK 的管理员登录地址默认是本机 `http://127.0.0.1:8787`，用 `admin` 和首次显示的管理员密码登录。

## 运行要求

- 主机手机必须开机、连接家庭 Wi-Fi，并保持「EffectCraft 家庭账号服务」常驻通知。
- 建议在 Android 电池设置中将本 APK 设置为「不限制」或允许后台运行；不同品牌名称可能不同。
- 手机重启后重新打开一次账号管理 APK，以重新启动账号服务。
- 账号数据库保存在主机手机应用私有目录中；卸载 APK 或清除应用数据会删除本地账号数据库。请勿随意卸载。
- 服务只绑定当前 Wi-Fi 的 IPv4 地址，并只接受同一 Wi-Fi 子网内的连接；断开 Wi-Fi 时服务停止对外提供接口。
- 不要在路由器上设置 8787 端口的公网转发。公共 Wi-Fi 不可用。

## 账号功能

- 用户注册：QQ号、微信号、姓名、密码、头像地址。
- 用户登录：QQ号或微信号加密码。
- 账号资料：显示头像、QQ号、微信号和姓名。
- 管理员：搜索账号、查看资料、按时间封禁、填写封禁原因、解除封禁。
- 每次启动 EffectCraft 时向主机手机验证账号状态；主机不可访问时保持账号页锁定。

## 安全说明

服务器不监听移动数据接口或公网接口，而是绑定当前 Wi-Fi IPv4；并再次检查客户端是否属于主机所在 Wi-Fi 子网。局域网 HTTP 不加 TLS，因此只应在自己信任且设置 WPA2/WPA3 密码的家庭 Wi-Fi 中使用，不要在公共网络使用，也不要把 8787 端口映射到公网。
