# EffectCraft 独立管理 APK

管理 APK 同时是管理员控制台和可手动启停的主账号服务器。管理员手机是账号权威数据源；普通主 APK 是客户端，不参与账号服务器托管，也不显示节点列表、连接状态或管理员操作入口。

## 管理员手机服务器开关

- 「开启服务器」：启动本机账号 API、账号数据库和安全认证服务；检查实际监听状态与外网可达性，并显示服务器运行状态、可达性、客户端连接数、最近同步时间。
- 「关闭服务器」：停止监听并拒绝新的账号请求；不删除账号数据。再次开启后恢复服务。
- 管理 APK 主页面持续显示真实状态：开关状态、服务进程状态、外网可达性、最近成功请求/同步时间、当前客户端数。不能只根据开关显示“在线”。
- 管理员手机关机、断网、应用被强行停止或系统暂停后台服务时，账号服务器不可用。Android 需要的前台服务通知和后台运行说明必须保留，不能伪装成永远在线。
- 管理员手机本地保存账号权威数据库；主 APK 客户端通过加密认证 API 注册、登录、更新资料并检查封禁状态。密码采用安全哈希，传输必须使用 TLS；JWT/会话密钥不得硬编码进 APK 或提交到仓库。
- 封禁、解禁和原因/期限由管理 APK 授权后写入管理员手机数据库，并通过账号 API 通知客户端；服务器离线期间客户端无法取得最新状态，重新连接后必须刷新。

## 跨地区连接的现实限制

管理员手机通常处于家庭路由器 NAT 或运营商 CGNAT 后面，单靠手机开启 TCP 端口不保证外网可连接。实现必须检测公网可达性。若无法直连，需要使用明确配置的安全反向隧道/中继，将流量转发到管理员手机；中继只负责传输，不保存账号数据库、不签发账号状态，也不能取代管理员手机作为权威服务器。不能宣称完全无中继、无任何公网基础设施且保证所有运营商都能连接。

## 旧版局域网节点实验

LanPeerDiscovery / LanServerService 是旧的同 Wi-Fi 实验实现，不是最终跨地区服务器方案。不得把 mDNS 发现成功说成跨地区账号服务已完成。最终界面应以管理员手机账号服务为核心，不再要求每部普通用户手机启动管理 APK 或成为节点。

## 安全与可靠性

- Android Keystore 保护管理员签名密钥；管理员凭据和 TLS 隧道凭据不得写入源码。
- 所有管理 API 必须进行管理员授权；普通用户令牌不得访问管理接口。
- 数据库写入采用事务和备份；关闭服务器不得删除账号。
- 对重复请求、重放、并发资料更新、封禁/解禁顺序和会话失效进行测试。
- 服务器不可达时明确提示，不能伪造注册/登录成功。
- Android 后台限制、耗电、发热和网络切换需要真实设备测试。

## 主 APK 保留项

主 APK 保留 EffectCraft 编辑器、RIFE 插帧、Real-ESRGAN 画质增强、项目导入导出、WASM 插件和桌面 AE 插件兼容导入等既有功能。DeepSeek 本地模型作为可导入插件资源，不捆绑进主 APK。
