# EffectCraft 独立管理 APK

管理 APK 同时提供两个**独立并存**的网络系统和两个独立开关。管理员手机既是账号主服务器，也是全网 P2P 节点网络的管理控制端；两个系统可以分别运行，不互相取代。

## 一、管理员手机账号服务器

管理员手机保存权威账号数据库，负责注册、登录、资料更新、账号状态、封禁/解禁、封禁原因和期限。主 APK 是账号客户端，不托管权威账号数据库。

- 「账号服务器」开启：启动本机账号 API、数据库和安全认证服务，并检测真实外网可达性。
- 「账号服务器」关闭：停止账号 API，不删除账号数据；重新开启后恢复。关闭期间在线注册、登录、资料同步和封禁状态检查不可用，客户端不得伪造成功。
- 管理员手机关机、断网、应用被强行停止或系统暂停服务时，账号服务器不可用。
- 手机可能处于 NAT/运营商 CGNAT 后面。必须检测外网可达性；必要时使用明确配置的安全反向隧道/中继。中继只转发加密流量，不保存账号数据库，管理员手机仍是唯一账号权威源。

## 二、P2P 手机节点网络

不同地区的手机可通过 P2P 建立节点连接，用于节点互联、节点状态交换和经授权的分布式计算任务（例如可拆分的视频帧处理、图片增强）。P2P 网络不取代管理员手机账号服务器，也不成为第二套权威账号数据库。

- 「P2P 节点网络」开启：允许节点发现、认证连接、任务分配/协作和结果回传。
- 「P2P 节点网络」关闭：停止节点发现、节点连接和分布式任务；不影响账号服务器本身。
- 节点之间必须加密通信、验证设备身份和签名控制消息；未经管理员授权的节点不能执行封禁/解禁。
- NAT/CGNAT 可能阻止直连；打洞和中继只能提高连接成功率，不能保证所有网络都能直连。Android 后台限制也可能暂停节点服务。
- 普通主 APK 不显示节点列表、连接状态、节点数量或管理开关；节点管理只在管理 APK。

## 两个开关的组合

| 账号服务器 | P2P 节点网络 | 结果 |
|---|---|---|
| 开 | 开 | 账号服务和节点互联同时运行 |
| 开 | 关 | 账号服务正常，节点互联/分布式任务停止 |
| 关 | 开 | P2P 节点网络可运行；在线账号操作不可用 |
| 关 | 关 | 两项网络服务都停止；本地编辑功能仍可用 |

管理版状态面板分别显示账号服务器进程状态、外网可达性、最近账号请求/同步时间，以及 P2P 网络真实可达性、最近节点同步时间和已验证节点数。不能只根据开关显示在线。

## 安全与可靠性

- Android Keystore 保护管理员签名密钥；管理员凭据、JWT 密钥和隧道凭据不得写入源码或 APK。
- 账号 API 使用 TLS 和强认证；普通用户令牌不能访问管理接口。
- 账号数据库事务写入并定期备份；关闭服务不得删除数据。
- P2P 节点须完成身份配对、加密会话、消息签名验证、重放保护和任务结果校验。
- 服务器或节点不可达时明确显示离线/未知，不伪造成功状态。
- 保留 Android 前台服务通知、后台限制和耗电说明，不得隐瞒节点运行。

## 主 APK 保留项

主 APK 保留 EffectCraft 编辑器、RIFE 插帧、Real-ESRGAN 画质增强、项目导入导出、WASM 插件和桌面 AE 插件兼容导入等既有功能。DeepSeek 本地模型作为可导入插件资源，不捆绑进主 APK。
