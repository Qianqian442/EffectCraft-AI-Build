# EffectCraft 管理版 APK

## 管理员手机账号权威端

- 管理版安装在管理员自己的 Android 手机上。
- 账号数据保存在这台手机的应用私有 SQLite 数据库中。
- 主 APK 只能通过经过身份验证和加密的私有 VPN 通道访问账号接口。
- VPN 账号通道仅用于注册、登录、会话验证、用户本人资料修改/删除，以及管理员用户管理、封禁/解禁。
- VPN 成员身份不等于管理员权限；管理接口必须再次验证管理员身份和签名/授权。
- 账号服务开关只控制账号接口；节点网络开关独立控制 P2P 节点参与。

## VPN 账号通道要求

- 账号监听器只绑定/接受来自 VPN 接口的已认证对端，不得向公共 Wi-Fi、移动数据或任意 LAN 接口开放。
- 通道使用 TLS 或等效的端到端认证加密；VPN 内也禁止明文传输可复用密码/令牌。
- VPN 断开时账号操作失败关闭，不得伪造成功，也不得回退到 Cloudflare、固定公网 URL、局域网明文 HTTP 或 localhost 假接口。
- 管理员手机 SQLite 数据库不上传、不暴露；账号服务关闭后停止监听并拒绝新请求。
- VPN 覆盖网络可能依赖 VPN 提供方的协调或加密中继来穿越 NAT/CGNAT。用户不需要租用或维护服务器，但不得声称在完全没有协调/中继基础设施时也保证跨网络可达。

## 节点网络

- 节点 P2P 网络与账号 VPN 通道分离；账号 VPN 不是媒体/视频/AI 模型中继。
- 管理版只管理全局节点网络开关，不作为工作节点。
- 节点 OFF 时关闭现有会话并停止新参与；ON 时允许符合条件的节点自动尝试重连。
- 局域网 UDP/mDNS 发现只能作为可选加速，不能成为跨网络连接的唯一机制。
- 跨网络直连受 NAT/CGNAT、热点隔离、运营商策略及 Android 后台限制影响；任何中继依赖必须如实披露。
- 账号服务开关与节点网络开关必须相互独立。

## 当前实现限制（不可误报为已完成）

- 当前账号服务代码仍是 LAN-only HTTP 监听器，使用 Wi-Fi IPv4/子网检查；尚未实现 VPN 接口绑定、VPN 对端认证和 TLS 账号传输。
- 当前 UDP/mDNS 发现仅适用于局域网。
- 当前构建不能宣称已支持 VPN 跨网络账号管理或跨地区节点互连。
- 不要在路由器上开放 8787、8788 或 8789 端口。
- VPN 真实连接、账号权限隔离、两台真实手机异网测试及 APK 安装验证完成前，不得发布为可用版本。

## 验收标准

1. 管理员手机与主 APK 手机在不同网络加入 VPN 覆盖网。
2. 主 APK 可通过 VPN 注册/登录，并只能修改/删除自己的账号。
3. 管理员可查询、修改、删除、封禁和解禁账号；封禁原因/期限留有审计记录。
4. 普通 VPN 成员无法调用管理员接口。
5. 账号服务 OFF 不影响节点开关；节点 OFF 不影响账号服务。
6. VPN 断开时账号接口不可访问；恢复后无需手动填写公网 IP。
7. 公网 Wi-Fi/移动数据接口无法直接访问账号监听器。
8. 两台真实 Android 手机异网完成双向账号请求测试。
9. 主 APK 保留原编辑器、RIFE、Real-ESRGAN、项目导入导出、插件及视频导出功能。
