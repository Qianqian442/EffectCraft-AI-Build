# EffectCraft 管理版 APK

## 当前方案：管理员手机作为账号主服务器

- 管理版安装在管理员自己的 Android 手机上。
- 账号数据保存在这台手机的应用私有 SQLite 数据库中；不使用 Cloudflare、D1 或外国云端账号库。
- 账号 API 使用本机 `127.0.0.1:8788`；主 APK 在同一 Wi-Fi 内通过 UDP `8789` 自动发现管理员手机，再连接账号 API。
- 账号服务器由管理版中的独立开关控制；关闭后，主 APK 无法注册、登录或验证。
- 节点互联由另一个独立开关控制，当前实现同一 Wi-Fi 的节点发现（TCP `8787`）。关闭节点网络不会关闭账号服务器。

## 手机使用要求

1. 在管理员手机安装管理版 APK。
2. 首次打开时，账号服务器默认启动；保持 Wi-Fi 已连接。
3. 使用管理员密码登录管理界面。
4. 保持管理版允许后台运行，并避免系统对它强制省电/清理。
5. 主 APK 当前必须与管理员手机连接同一 Wi-Fi，才能发现和访问账号服务器。

## 当前限制

- 当前版本已经实现管理员手机本地账号库和同一 Wi-Fi 自动发现。
- 不支持跨城市、跨运营商的公网账号访问；手机常见的运营商级 NAT 会阻止外部设备直接连入。
- 跨地区需要完成 libp2p AutoNAT、Circuit Relay、DCUtR 打洞及国内可用的中继/引导节点配置；这些功能尚未端到端实现。
- 不要在路由器上开放 8787、8788 或 8789 端口，也不要把账号数据库暴露到公网。
- 当前 APK 构建未进行真实手机安装测试。
