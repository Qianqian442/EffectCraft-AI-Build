# EffectCraft 家庭账号服务器（仅家庭 Wi-Fi）

此服务供普通版 EffectCraft APK 和独立账号管理 APK 使用。账号数据保存在运行服务器的家用电脑磁盘中，不使用第三方账号云。

## Windows 家用电脑快速启动

1. 安装并启动 Docker Desktop（首次运行需要完成 Docker Desktop 的初始化）。
2. 双击 `start-server.bat`。
3. 首次启动时设置管理员密码（至少12位），记住它；管理员 APK 使用用户名 `admin` 和这个密码登录；服务器只保存该密码的 PBKDF2-SHA256 哈希。
4. 等待 Docker 下载依赖并启动容器。
5. 在家用电脑打开命令提示符，执行 `ipconfig`，查看当前 Wi-Fi 网卡的 IPv4 地址，例如 `192.168.1.23`。
6. 手机连接同一个家庭 Wi-Fi。普通版和管理员版中的服务器地址填写 `http://192.168.1.23:8787`（把示例 IP 换成实际 IP）。
7. Windows 防火墙询问时，仅允许“专用网络”访问。不要为 8787 端口设置路由器公网端口转发。

可以在路由器中给这台电脑设置 DHCP 地址保留，避免家庭 Wi-Fi 下 IP 变化。

## 功能

- QQ号、微信号、姓名、头像地址和密码注册；登录时使用 QQ号或微信号及密码。
- 密码使用 Argon2id 哈希，不保存明文密码；账号查询接口不会返回密码或密码哈希。
- 管理员单独登录；可按 QQ号、微信号、姓名搜索账号，查看个人资料，设置精确到分钟的封禁到期时间和原因，也可以解除封禁。
- 普通版每次启动时必须向此服务验证账号状态。账号被封禁时，服务器会返回封禁截止时间和原因；服务器不可用时，普通版保持锁定，不允许离线绕过。

## 网络边界与注意事项

此版本仅供可信的家庭 Wi-Fi 局域网使用。服务器监听家庭电脑的网卡，**不要**在路由器中开启公网端口转发，也不要将 8787 端口暴露到互联网。请使用 WPA2/WPA3 家庭 Wi-Fi 密码并只允许专用网络通过系统防火墙。HTTP 流量在局域网内未加 TLS 加密，因此不要在不可信的公共 Wi-Fi 使用，也不要复用其他重要服务的密码。

服务端电脑需要保持开机，手机才能注册、登录和检查封禁状态。电脑关机、服务退出或家庭 Wi-Fi 断开时，普通版将停留在账号验证页，不能进入编辑器。SQLite 数据库保存在 Docker 命名卷 `effectcraft-account-data` 中；备份时请停止容器并备份该卷。

## 数据格式

数据库保存在服务容器的 `/data/effectcraft-accounts.sqlite3`。管理员口令以 PBKDF2-SHA256 哈希形式保存在服务器环境文件 `.env` 中；请勿上传或分享 `.env`。管理员令牌有效期8小时，普通用户令牌有效期30天，但普通用户每次启动仍须在线核验封禁状态。
